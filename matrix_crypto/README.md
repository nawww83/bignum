# matrix_crypto (C++)

C++-порт матричной криптосистемы (**ElGamal + Schnorr над подгруппой `<T>` простого
порядка `q` в `SL_3(F_p)`**), построенный на header-only библиотеке
[`bignum`](../README.md) (типы `U128`, `UBig<Half>`).

Реализация **двоично совместима** с Python-версией из проекта `matrix_cipher`:
одни и те же параметры `p, q, T`, та же сериализация, тот же SHA-512-хэш,
тот же base64/JSON-конверт и те же ключевые файлы.

## Что внутри

| Файл | Назначение |
|------|-----------|
| `matrix_params.hpp` | параметры `p` (1023 бита), `q` (256 бит), `T` — генерируются `gen_cpp_params.py` |
| `matrix_crypto.hpp` | ядро: `Mat3`, арифметика над `F_p`, `mat_pow/mat_inv/mat_det`, сериализация, кодирование текста в блоки, `hash_to_scalar` |
| `cipher_tool.hpp` | Эль-Гамаль, подпись Шнорра, аутентифицированный конверт (encrypt-then-sign), чтение/запись ключей |
| `dh_secure.hpp` | аутентифицированный матричный Диффи-Хеллман (подпись Шнорра над пакетом, сессионный ключ = SHA-256) |
| `sha2.hpp` | SHA-512 и SHA-256 (FIPS 180-4), совместимы с `hashlib` |
| `base64.hpp` | Base64 (RFC 4648) |
| `main.cpp` | CLI и самотест |

## Типы и разрядность

```
U256  = UBig<U128>          — скаляры (экспоненты, порядок q)
U1024 = UBig<U512>          — элементы поля F_p (p — 1023 бита)
U2048 = UBig<U1024>         — расширенное произведение для mulmod
U16384 = UBig<U8192>        — промежуточный тип кодирования сообщения (~1800 байт)
```

Модульное умножение: `mod_mul(a,b) = (U2048::mult_ext(a,b) / P()).second` —
расширение разрядности через `mult_ext` и деление на «половинку» (быстрый путь Кнута).

## Сборка

```bash
cd ~/bignum/matrix_crypto
cmake -S . -B build && cmake --build build -j
# или напрямую:
g++ -std=c++20 -O2 -I .. main.cpp -o matrix_crypto
```

## Запуск

```bash
./build/matrix_crypto keygen                 # public_key.json / private_key.json
./build/matrix_crypto encrypt "Секрет"       # аутентифицированный конверт
./build/matrix_crypto decrypt "<BASE64>"     # расшифровать (проверяет подпись)
./build/matrix_crypto sign "Текст"           # подпись Шнорра
./build/matrix_crypto verify "Текст" "<B64>" # ВЕРНА / ОШИБКА
./build/matrix_crypto dh                     # демо аутентифицированного DH (2 стороны)
./build/matrix_crypto selftest               # 27 проверок + демонстрация атак
./build/matrix_crypto params
```

Скриптовые (`-b64`) режимы принимают сообщение в base64 — удобно для интеропа:
`sign-b64`, `verify-b64`, `seal-b64`, `open`.

Односторонние команды для DH (для кросс-проверки/интеграции):

```bash
# своя сторона: D = T^eph, пакет + подпись
./build/matrix_crypto dh-publish PRIV_FILE EPH_DEC      # -> PACKET, SIG

# проверка подписи пира и вычисление общего секрета
./build/matrix_crypto dh-derive EPH_DEC PEER_PUB_FILE PEER_PACKET PEER_SIG
                                                        # -> SHARED_HEX, SESSION_KEY
```

## Схема (кратко)

* **Параметры.** `q | p² + p + 1`, `q ≡ 1 (mod 3)` — простое; `T = C^((p²+p+1)/q)`,
  где `C` — сопровождающая матрица неприводимого кубического многочлена над `F_p`.
  `order(T) = q`.
* **Шифрование (Эль-Гамаль):** `C1 = T^r`, `C2 = P · Y^r`; `P = C2 · (C1^x)⁻¹`.
* **Подпись (Шнорр):** `R = T^k`, `e = SHA512(R ‖ msg) mod q`, `s = k + e·x mod q`;
  проверка `T^s == R · Y^e`.
* **Аутентификация шифртекста:** `sealed = base64({"v":2,"ct":…,"sig":Sign(ct)})` —
  сначала проверяется подпись, затем расшифрование (защита от мультипликативной
  изменяемости сырого Эль-Гамаля `C2' = Z·C2 → Z·P`).
* **Аутентифицированный DH:** `A = T^a`, `B = T^b`, общий секрет `T^(ab)`; каждый
  пакет подписан Шнорром, поэтому подмена пакета (MitM) обнаруживается. Сессионный
  ключ = `SHA-256(serialize(T^(ab)))`.

## Ограничения

* Сообщение ≤ ~1800 байт в одной операции (ограничение широкого типа `U16384`).
* Стойкость — как у дискретного логарифма в `<T>` (generic ≈ 2¹²⁸); не постквантовая.
* Реализация учебная: примитивы не константного времени.
